# upupup

A tiny one-page site. One-on-one help to get better with computers.

## Add your photos

Drop your images into `images/` and name them `photo-1`, `photo-2`, `photo-3`.
If you use `.jpg`/`.png` instead of `.svg`, update the `src` in `index.html` to match.

## Edit the words

Everything lives in `index.html`. Change the tagline, intro, and contact email there.

## Hosting

Served by GitHub Pages from the `main` branch. Any push to `main` updates the live site.
